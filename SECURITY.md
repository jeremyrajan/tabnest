# Security

Please do not open a public issue for a vulnerability that could expose browsing data or unexpectedly modify tabs.

Use the repository’s **Security** tab to submit a private vulnerability report. Include the affected Tabnest version, Chrome version, reproduction steps, and the impact. Avoid including private URLs, page descriptions, or browsing data.

Tabnest runs locally and intentionally has no network requests. Changes that introduce external data transmission require explicit documentation and review.
